# Professional Jarvis AI Assistant

Offline AI Voice Assistant built using Python, Vosk and SoundDevice.

## Features

- Offline Voice Recognition
- Wake Word Detection
- Open Applications
- Open Websites
- Screenshot Capture
- YouTube Search
- Google Search
- Text To Speech

## Technologies

- Python
- Vosk
- SoundDevice
- pyttsx3
